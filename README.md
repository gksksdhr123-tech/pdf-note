# PDF Note

원본 PDF는 그대로 두고, 필기(잉크)만 따로 저장하는 가벼운 개인용 PDF 노트 웹앱입니다.
서버 없이 브라우저(IndexedDB)에만 데이터를 저장하는 정적 사이트라 빌드 과정이 없습니다.

## 특징

- 원본 PDF 파일은 절대 수정하지 않습니다. 필기는 IndexedDB에 PDF별로 따로 저장됩니다.
- 같은 PDF를 다시 열면 자동으로 필기가 불러와집니다. 매번 새 파일을 만들지 않습니다.
- 필기할 때마다 즉시 자동 저장됩니다. 별도의 "저장" 버튼이 없습니다.
- File System Access API를 지원하는 브라우저(최신 Chrome 등)에서는 PDF 파일 자체를 복사해서 저장하지 않고, 파일 위치에 대한 가벼운 참조만 기억해뒀다가 다시 읽어옵니다 — 기기 저장공간을 두 배로 쓰지 않습니다. 지원하지 않는 브라우저에서는 예전처럼 파일을 캐시해 둡니다(그래야 다시 열 수 있어서).
- S펜 등 필압을 지원하는 입력장치는 압력에 따라 선 굵기가 달라집니다.
- 손가락 터치는 그리기에 반응하지 않고 스크롤/화면 이동에만 사용됩니다 (펜/마우스만 필기). 펜으로 화면을 움직이고 싶으면 "이동" 도구(손모양)를 선택하면 됩니다.
- 손가락 두 개로 핀치 줌 지원 (제스처 중엔 화면만 즉시 축소/확대되고, 손을 떼면 실제 배율로 다시 그려집니다).
- 필요할 때 "내보내기"를 누르면 필기(그리고 현재 가려진 암기 마스크)를 원본 위에 합친 새 PDF 파일을 다운로드할 수 있습니다.
- "자동 넘김"을 켜두면 페이지 끝까지 스크롤했을 때 자동으로 다음/이전 페이지로 넘어갑니다. 툴바에서 언제든 끄고 켤 수 있습니다.
- 설정(⚙)에서 폴더를 하나 지정하면, 필기·마스크가 문서별 JSON 파일로도 그 폴더에 자동 저장됩니다. 기기 브라우저 저장소와 별개로 남는 진짜 파일이라 백업/동기화에 쓸 수 있습니다 (PDF 원본은 여기 저장되지 않습니다). File System Access API를 지원하는 브라우저에서만 가능합니다.
- 뷰어 상단의 "페이지 보기"에서 문서의 모든 페이지를 썸네일로 보고 바로 이동할 수 있고, 페이지 사이사이의 "+"로 흰 페이지/줄 노트/격자/이미지를 끼워 넣을 수 있습니다. 끼워 넣은 페이지는 원본 PDF를 건드리지 않고 앱 안에서만 유지되다가, 내보내기할 때 실제 PDF에 합쳐집니다.
- PWA로 지원되어 홈 화면에 설치해 앱처럼 쓸 수 있고, 오프라인에서도 동작합니다.

### 암기모드

"가리기" 도구로 페이지 일부를 사각형으로 가려 놓고, 1~5번 그룹으로 나눠 각각 다른 색을 줄 수 있습니다.

- "암기모드"를 켜면 활성화된 그룹이 완전히 불투명하게 덮여 안 보이게 됩니다. 이 상태에서 개별 그룹 번호를 끄면 그 그룹만 다시 보이고, 나머지는 계속 가려진 채로 남습니다. "암기모드" 자체를 끄면 전부 보입니다 — 켜고 끌 때마다 바로 반영됩니다.
- "모두 보기" / "모두 가리기"로 한 번에 전체 그룹을 전환할 수 있습니다.
- 지우개로 마스크도 지울 수 있습니다 (펜 스트로크와 동일하게 undo/redo 지원).
- 마스크가 하나라도 있는 페이지는 홈 화면의 "암기카드" 목록에 자동으로 모입니다. 카드를 탭하면 전체화면으로 크게 보면서 탭(또는 "정답 보기" 버튼)으로 가림/보임을 전환할 수 있고, 여러 문서의 마스크된 페이지를 이어서 넘겨볼 수 있습니다.

## 로컬에서 실행하기

ES 모듈과 Service Worker를 쓰기 때문에 `file://`로 직접 열면 동작하지 않습니다. 아무 정적 서버로 실행하세요.

```bash
cd docs
npx serve .
# 또는
python3 -m http.server 8080
```

## GitHub Pages로 배포하기

저장소 Settings → Pages → Source가 `main` 브랜치의 `/docs` 폴더로 지정돼 있고, 앱 파일이 전부 `docs/` 아래에 있어서 `main`에 푸시하면 그대로 배포됩니다. `https://<사용자명>.github.io/pdf-note/` 로 접속하면 되고, 태블릿 브라우저(Chrome 등)에서 접속 후 "홈 화면에 추가"로 설치하면 일반 앱처럼 아이콘을 눌러 바로 실행할 수 있습니다.

## 폴더 구조

```
docs/index.html        진입점, 모든 화면 마크업 (홈/뷰어/페이지 보기/암기카드/설정 등)
docs/css/style.css      스타일
docs/js/app.js          화면 전환, 이벤트 연결, 페이지 순서·삽입, 암기카드 렌더링
docs/js/db.js           IndexedDB 저장 (문서, 페이지별 필기·마스크, 페이지 순서, 설정)
docs/js/pdf-engine.js    pdf.js 래퍼 (렌더링) + 삽입 페이지(빈/줄/격자/이미지)용 가짜 뷰포트
docs/js/annotate.js      필기+마스크 캔버스 레이어 (펜/지우개/가리기/이동, 압력, 핀치줌, undo/redo, 암기모드 상태)
docs/js/export.js        pdf-lib로 원본 페이지 복사 + 삽입 페이지 생성 + 필기·마스크를 합쳐 새 PDF 내보내기
docs/js/notesfile.js     필기·마스크를 사용자가 고른 폴더에 JSON으로 백업
docs/vendor/             pdf.js, pdf-lib 빌드 결과물 (오프라인 동작을 위해 저장소에 포함)
docs/manifest.webmanifest, docs/sw.js  PWA 설정
```

(파일들이 `docs/` 아래에 있는 이유는 순전히 GitHub Pages의 배포 소스 설정이 `/docs`로 돼 있기 때문입니다 — Settings → Pages에서 소스를 `/ (root)`로 바꾸면 언제든 루트로 다시 옮길 수 있습니다.)

## 알려진 제한

- 여러 기기 간 동기화 없음 (기기 로컬 저장소 + 선택적으로 지정한 백업 폴더에만 저장됨)
- 암기모드 on/off, 그룹별 보임 상태는 문서를 다시 열면 초기화됩니다 (마스크 자체는 계속 저장됨)
- 파일 위치 참조(File System Access API)를 지원하지 않는 브라우저에서 파일 접근 권한이 사라지면(예: 브라우저에서 직접 권한을 취소한 경우) 같은 파일을 다시 선택해달라고 안내합니다
- 삽입한 페이지(빈/줄/격자/이미지)는 폴더 백업 대상이 아니고 기기 저장소에만 있습니다 — 필기·마스크만 폴더에 백업됩니다
