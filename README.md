# PDF Note

원본 PDF는 그대로 두고, 필기(잉크)만 따로 저장하는 가벼운 개인용 PDF 노트 웹앱입니다.
서버 없이 브라우저(IndexedDB)에만 데이터를 저장하는 정적 사이트라 빌드 과정이 없습니다.

## 특징

- 원본 PDF 파일은 절대 수정하지 않습니다. 필기는 IndexedDB에 PDF별로 따로 저장됩니다.
- 같은 PDF를 다시 열면 자동으로 필기가 불러와집니다. 매번 새 파일을 만들지 않습니다.
- 필기할 때마다 즉시 자동 저장됩니다. 별도의 "저장" 버튼이 없습니다.
- S펜 등 필압을 지원하는 입력장치는 압력에 따라 선 굵기가 달라집니다.
- 손가락 터치는 그리기에 반응하지 않고 스크롤/화면 이동에만 사용됩니다 (펜/마우스만 필기).
- 필요할 때 "내보내기"를 누르면 필기(그리고 현재 가려진 암기 마스크)를 원본 위에 합친 새 PDF 파일을 다운로드할 수 있습니다.
- PWA로 지원되어 홈 화면에 설치해 앱처럼 쓸 수 있고, 오프라인에서도 동작합니다.

### 암기모드

"가리기" 도구로 페이지 일부를 사각형으로 가려 놓고, 1~5번 그룹으로 나눠 각각 다른 색을 줄 수 있습니다.

- 가리기 도구를 선택한 동안은 항상 반투명하게 보여서(원본이 비침) 어디를 가릴지 보면서 그릴 수 있습니다.
- "암기모드"를 켜면 활성화된 그룹이 완전히 불투명하게 덮여 안 보이게 됩니다. 이 상태에서 개별 그룹 번호를 끄면 그 그룹만 다시 보이고, 나머지는 계속 가려진 채로 남습니다. "암기모드" 자체를 끄면 전부 보입니다.
- "모두 보기" / "모두 가리기"로 한 번에 전체 그룹을 전환할 수 있습니다.
- 지우개로 마스크도 지울 수 있습니다 (펜 스트로크와 동일하게 undo/redo 지원).
- 마스크가 하나라도 있는 페이지는 홈 화면의 "암기카드" 목록에 자동으로 모입니다. 카드를 탭하면 전체화면으로 크게 보면서 탭(또는 "정답 보기" 버튼)으로 가림/보임을 전환할 수 있고, 여러 문서의 마스크된 페이지를 이어서 넘겨볼 수 있습니다.

## 로컬에서 실행하기

ES 모듈과 Service Worker를 쓰기 때문에 `file://`로 직접 열면 동작하지 않습니다. 아무 정적 서버로 실행하세요.

```bash
npx serve .
# 또는
python3 -m http.server 8080
```

## GitHub Pages로 배포하기

1. GitHub 저장소 설정 → Pages → Source를 `main` 브랜치 `/ (root)`로 지정합니다.
2. 몇 분 후 `https://<사용자명>.github.io/pdf-note/` 로 접속됩니다.
3. 태블릿 브라우저(Chrome 등)에서 접속 후 "홈 화면에 추가"로 설치하면 일반 앱처럼 아이콘을 눌러 바로 실행할 수 있습니다.

## 폴더 구조

```
index.html        진입점, 홈 / 뷰어 / 암기카드 목록 / 카드 학습 화면 마크업
css/style.css      스타일
js/app.js          화면 전환, 이벤트 연결, 암기카드 목록·학습 화면 렌더링
js/db.js           IndexedDB 저장 (문서, 페이지별 필기·마스크)
js/pdf-engine.js    pdf.js 래퍼 (렌더링)
js/annotate.js      필기+마스크 캔버스 레이어 (펜/지우개/가리기, 압력, undo/redo, 암기모드 상태)
js/export.js        pdf-lib로 필기·마스크를 합쳐 새 PDF 내보내기
vendor/             pdf.js, pdf-lib 빌드 결과물 (오프라인 동작을 위해 저장소에 포함)
manifest.webmanifest, sw.js  PWA 설정
```

## 알려진 제한 (다음 버전 후보)

- 핀치 줌 대신 +/- 버튼으로만 확대/축소
- 여러 기기 간 동기화 없음 (기기 로컬 저장소에만 저장됨)
- 암기모드 on/off, 그룹별 보임 상태는 문서를 다시 열면 초기화됩니다 (마스크 자체는 계속 저장됨)
