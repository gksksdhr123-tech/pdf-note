# PDF Note

원본 PDF는 그대로 두고, 필기(잉크)만 따로 저장하는 가벼운 개인용 PDF 노트 웹앱입니다.
서버 없이 브라우저(IndexedDB)에만 데이터를 저장하는 정적 사이트라 빌드 과정이 없습니다.

## 특징

- 원본 PDF 파일은 절대 수정하지 않습니다. 필기는 IndexedDB에 PDF별로 따로 저장됩니다.
- 같은 PDF를 다시 열면 자동으로 필기가 불러와집니다. 매번 새 파일을 만들지 않습니다.
- 필기할 때마다 즉시 자동 저장됩니다. 별도의 "저장" 버튼이 없습니다.
- S펜 등 필압을 지원하는 입력장치는 압력에 따라 선 굵기가 달라집니다.
- 손가락 터치는 그리기에 반응하지 않고 스크롤/화면 이동에만 사용됩니다 (펜/마우스만 필기).
- 필요할 때 "내보내기"를 누르면 필기를 원본 위에 합친 새 PDF 파일을 다운로드할 수 있습니다.
- PWA로 지원되어 홈 화면에 설치해 앱처럼 쓸 수 있고, 오프라인에서도 동작합니다.

## 로컬에서 실행하기

ES 모듈과 Service Worker를 쓰기 때문에 `file://`로 직접 열면 동작하지 않습니다. 아무 정적 서버로 실행하세요.

```bash
npx serve .
# 또는
python3 -m http.server 8080
```

## GitHub Pages로 배포하기

1. GitHub 저장소 설정 → Pages → Source를 `main` 브랜치 `/ (root)`로 지정합니다.
2. 몇 분 후 `https://<사용자명>.github.io/pdf-note/` 로 접속됩니다.
3. 태블릿 브라우저(Chrome 등)에서 접속 후 "홈 화면에 추가"로 설치하면 일반 앱처럼 아이콘을 눌러 바로 실행할 수 있습니다.

## 폴더 구조

```
index.html        진입점, 홈 화면 / 뷰어 화면 마크업
css/style.css      스타일
js/app.js          화면 전환, 이벤트 연결
js/db.js           IndexedDB 저장 (문서, 페이지별 필기)
js/pdf-engine.js    pdf.js 래퍼 (렌더링)
js/annotate.js      필기 캔버스 레이어 (펜/지우개, 압력, undo/redo)
js/export.js        pdf-lib로 필기를 합쳐 새 PDF 내보내기
vendor/             pdf.js, pdf-lib 빌드 결과물 (오프라인 동작을 위해 저장소에 포함)
manifest.webmanifest, sw.js  PWA 설정
```

## 알려진 제한 (다음 버전 후보)

- 펜/지우개, 색상, 굵기만 지원 (텍스트 하이라이트, 도형, 텍스트 박스는 아직 없음)
- 핀치 줌 대신 +/- 버튼으로만 확대/축소
- 여러 기기 간 동기화 없음 (기기 로컬 저장소에만 저장됨)
